# Composant Popover

> Boîte contextuelle riche déclenchée au clic (contrairement au tooltip ou menu).

## Import
```tsx
import { Popover, PopoverAnchor, PopoverContent, PopoverTrigger } from '@dsfrkit/react'
```

## Usage recommandé
Boîte contextuelle riche déclenchée au clic (contrairement au tooltip ou menu). Idéale pour des contenus interactifs complexes. Contenu flottant interactif déclenché au **clic**. Pour un aperçu non interactif au survol, utilisez le composant **HoverCard**.
