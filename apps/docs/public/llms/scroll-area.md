# Composant ScrollArea

## Import
```tsx
import { ScrollArea } from '@dsfrkit/react'
```

## Documentation et Usages
Composant ScrollArea
Un conteneur défilant qui personnalise l'apparence des barres de défilement pour s'intégrer parfaitement au DSFR.
@example
```tsx
<ScrollArea className="h-72 w-48 border">
<div className="p-4">
Contenu très long...
</div>
</ScrollArea>
```
