# Documentation DSFRKit

Application de documentation et playground pour DSFRKit.

## Développement

```bash
pnpm install
pnpm dev
```

Ouvrez [http://localhost:5173](http://localhost:5173) dans votre navigateur.

## Build

```bash
pnpm build
pnpm preview
```

## Contenu

Cette application montre :
- Tous les composants disponibles
- Les variants et tailles
- La palette de couleurs DSFR
- La typographie Marianne
- Des exemples d'utilisation
