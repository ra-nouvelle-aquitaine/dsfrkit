# Composant Indicator

## Import
```tsx
import { Indicator } from '@dsfrkit/react'
```

## Documentation et Usages
Composant générique permettant d'ajouter une pastille (notification, badge numérique)
sur n'importe quel élément (souvent une icône).
@example
```tsx
<Indicator count={5}>
<NotificationIcon />
</Indicator>
```
