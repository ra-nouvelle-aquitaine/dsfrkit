Son objectif est de garantir une accessibilité irréprochable, le respect rigoureux de la charte graphique de l'État, et d'excellentes performances.
    </Text>
    <Text className="text-foreground-muted block mb-4">

Ils s'intègrent parfaitement dans vos applications fonctionnant côté client (CSR) ou côté serveur (SSR).
    </Text>

Vous devenez ainsi entièrement propriétaire du code, et libre de l'adapter en fonction des règles métiers de votre application !

Cette approche est très pratique pour réaliser des prototypes rapidement ou pour limiter la quantité de code importé dans votre dépôt.
