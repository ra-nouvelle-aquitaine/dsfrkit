# Composant Highlight

> Mise en valeur d'un texte court ou d'une citation dans le flux de lecture.

## Import
```tsx
import { Highlight } from '@dsfrkit/react'
import type { HighlightProps } from '@dsfrkit/react'
```

## Usage recommandé
Mise en valeur d'un texte court ou d'une citation dans le flux de lecture.

## Props et types
```ts
export interface HighlightProps
  extends React.HTMLAttributes<HTMLDivElement>,
    VariantProps<typeof highlightVariants> {}
```
